# Learning by Building

A collection of hands-on projects, experiments, and infrastructure configurations built as part of a continuous learning journey.

The purpose of this repository is to explore technologies by building with them — understanding how things work, experimenting with different approaches, and gradually turning concepts into practical implementations.

## 🌱 Continuous Learning

I'm continuously learning, experimenting, and building across different areas of technology.

This repository will evolve over time as I explore new tools, platforms, technologies, and engineering concepts.

Some of the current areas of exploration include:

- Infrastructure as Code
- Cloud Computing
- Automation
- DevOps
- Networking
- Systems & Infrastructure
- Software Engineering

## 🛠️ Approach

I believe the best way to learn is to build.

Rather than simply following tutorials, I use this repository to:

- Experiment with new concepts
- Build things from scratch
- Break things and understand why
- Try different approaches
- Refactor and improve existing implementations
- Document useful patterns and lessons

## 📂 Repository

Projects are organized by topic and technology, with each directory containing the configuration and code related to that particular experiment or project.

The structure will evolve as new areas are explored.

## 🚀 Always Learning

This repository is intentionally a work in progress.

New projects, experiments, and technologies will be added over time as I continue learning and expanding my technical skills.
